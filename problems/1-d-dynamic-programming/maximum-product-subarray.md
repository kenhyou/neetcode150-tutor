# Maximum Product Subarray

- **Category:** 1-D Dynamic Programming · **Difficulty:** Medium
- **LeetCode:** https://leetcode.com/problems/maximum-product-subarray/
- **Patterns:** DP

## Problem
Given an integer array `nums`, find the contiguous non-empty subarray with the largest
product, and return that product. The answer fits in a 32-bit integer.

## Examples
**Example 1**
- Input: `nums = [2, 3, -2, 4]`
- Output: `6`  (subarray `[2, 3]`)

**Example 2**
- Input: `nums = [-2, 0, -1]`
- Output: `0`

## Constraints
- `1 <= nums.length <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
