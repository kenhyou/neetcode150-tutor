# Trapping Rain Water

- **Category:** Two Pointers · **Difficulty:** Hard
- **LeetCode:** https://leetcode.com/problems/trapping-rain-water/
- **Patterns:** Two Pointers, Monotonic Stack

## Problem
Given `n` non-negative integers `height` representing an elevation map where each bar
has width 1, compute how much rainwater can be trapped between the bars after it
rains.

## Examples
**Example 1**
- Input: `height = [0,1,0,2,1,0,1,3,2,1,2,1]`
- Output: `6`

**Example 2**
- Input: `height = [4, 2, 0, 3, 2, 5]`
- Output: `9`

## Constraints
- `1 <= height.length <= 2 * 10^4`
- `0 <= height[i] <= 10^5`
