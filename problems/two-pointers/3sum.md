# 3Sum

- **Category:** Two Pointers · **Difficulty:** Medium
- **LeetCode:** https://leetcode.com/problems/3sum/
- **Patterns:** Two Pointers, Sorting

## Problem
Given an integer array `nums`, return all **unique** triplets `[a, b, c]` such that
`a + b + c == 0`. The solution set must not contain duplicate triplets, but the order
of triplets (and of values within them) does not matter.

## Examples
**Example 1**
- Input: `nums = [-1, 0, 1, 2, -1, -4]`
- Output: `[[-1, -1, 2], [-1, 0, 1]]`

**Example 2**
- Input: `nums = [0, 1, 1]`
- Output: `[]`

**Example 3**
- Input: `nums = [0, 0, 0]`
- Output: `[[0, 0, 0]]`

## Constraints
- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`
