# Valid Anagram

- **Category:** Arrays & Hashing · **Difficulty:** Easy
- **LeetCode:** https://leetcode.com/problems/valid-anagram/
- **Patterns:** Hash Map, Counting

## Problem
Given two strings `s` and `t`, return `true` if `t` is an anagram of `s` — that is,
`t` uses exactly the same characters as `s` with the same frequencies, just possibly
reordered. Otherwise return `false`.

## Examples
**Example 1**
- Input: `s = "anagram"`, `t = "nagaram"`
- Output: `true`

**Example 2**
- Input: `s = "rat"`, `t = "car"`
- Output: `false`

## Constraints
- `1 <= s.length, t.length <= 5 * 10^4`
- `s` and `t` consist of lowercase English letters.

**Follow-up:** What if the inputs contain Unicode characters?
